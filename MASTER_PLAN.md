# Version 1 scope

The current scope is automatic video creation and QC-gated YouTube publication, a one-page personal dashboard, bounded retries, protected credentials, limited object storage and seven-day retention.

The implementation and operational limits are documented in [IMPLEMENTATION_REPORT.md](IMPLEMENTATION_REPORT.md). Deployment and maintenance procedures are in [DEPLOYMENT.md](DEPLOYMENT.md). This replaces the old multiphase roadmap; unfinished analytics, recommendation and thumbnail pipelines are excluded. Existing basic rendering templates remain shared pipeline code, with no advanced animation feature added.
